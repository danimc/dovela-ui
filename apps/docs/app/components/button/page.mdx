# Button

A button built on React Aria's `Button`. It renders a native `<button>`, handles
keyboard activation and press states across mouse, touch and pen, and exposes
its state through `data-*` attributes that the variants style.

<CodeBlock code={`import { Button } from "@my-ui/react";`} />

## Disabled

Use `isDisabled` rather than the native `disabled` attribute — React Aria keeps
the button out of the tab order and suppresses `onPress`.

<Preview code={`<Button isDisabled>Disabled</Button>`}>
  <Button isDisabled>Disabled</Button>
</Preview>
